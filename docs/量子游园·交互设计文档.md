## 0. 一句话概念

牡丹亭《游园惊梦》× 量子力学的沉浸式交互装置：**满园之字皆在叠加态，观测（目光/指针）使其坍缩为真**。观众以"看"游园，以"气"惊梦，以"行"寻梦——每一幕用一个量子概念讲一折戏。

## 2. 全局交互语言（所有幕共用）

### 2.1 观测-坍缩模型（核心）
- 每个字粒（item）有工程变量 **凝定度/显真度 `c ∈ [0,1]`**，初始 0（叠加态）。`c` 越高表示字越被观测、越凝真；它不是严格物理意义的量子相干度，文案与论文不得把数值包装成真实量子数据。
- 叠加态表现：位置游移（幅度 `jamp` 0.12–0.30 × (1-c)）、字形闪变（随机换字，频率 ∝ (1-c)）、冷玉灰、透明度 0.20、字号 82%。
- 指针柔光圈（半径 `BRUSH` = 短边 20%）内，c 上升：`c += (influence−c)×(1−0.88^(dt×60))`，influence 为 smoothstep 软边；按 `dt` 归一，60/120Hz 不改变手感。
- **c 只升不降（latch）**：扫过即留，不退相干。
- c≥0.55 显示真字；颜色/透明度/字号随 c 线性插值到本色；c≥0.8 才触发事件。
- 显真字阈 0.55 / 事件阈 0.8（两者脱钩缘由见§8坑7）。
- **計白當黑，字不相叠（族规，2026-06-12 一葳定）**：字间之白即构图，中国书画不叠图层。引擎以碰撞盒保证零叠字；**任何后置浮现的特殊字（卷、门字、款识等）必须在 compose 时预留其白**（幽灵碰撞盒占位，如太湖石之"漏"窍藏卷）——显形是"白处生字"，不是叠加覆盖。出口字的暗底衬纸=运行时的临时让位，属同一原则。

### 2.2 指针
- 画布隐藏系统光标（`cursor:none`）。reveal 幕：骨白柔光场+未闭合朱砂观测环+中心点；blow 幕（惊梦台）：只留小观测环，近可点目标时**变亮变大+中心点**。

### 2.3 出口（门）通用
- 一律**单字出口**（无框无拱）：暗底衬纸（径向光晕）+ 朱砂单字（`pulse=0.5+0.5sin(2.2t)` 只调透明度）。朱砂在全作只表示“此处可行动”。
- `gateReady` 置位后 `gateA` 以 **2.6s** 渐升，整体 globalAlpha 渐显——门"缓缓显形"，永不闪现。
- 点击半径 `passR ≈ R×1.6`（R = 短边×0.078）。→ 键等效点门（惊梦台叠加态中键盘也过不去）。
- 过场：1.6s 黑场淡入淡出（`trans`），中点换景。末幕→回首幕（循环）。

### 2.4 键盘
`空格`=惊梦/再夢（惊梦台）｜`→`=前行｜`R`=重看本景｜桌面端右下只显“空格 · → · R”微型提示，移动端隐藏。

### 2.6 提示语文风（族规，2026-06-12 定）
- 提示语 / 入园副题 / 谢幕卡等一切 UI 文案，标点**一律全角**（，；：（）？）。半角 `,;()` 在宋体竖排美学下留出西文窄空、观感破相——伍·離魂/陸·拾畫叫畫已统一，新幕勿再分叉。代码内标点不受此限。
- **进度与幕号只说中国话**（2026-06-12 一葳定）：禁百分比、禁阿拉伯数字——进度用成数（"拂亮四成/將滿"）、计数用汉字数词（HN）、幕号用 `MU=['壹','貳','參','柒']`（对齐八幕总谱，桥=第柒幕）。
- **展示文案不再有「試驗稿」等测试字样**（2026-06-13）：只留正式名称；稿别只许活在代码注释与文档里。
- **总入场、预备幕与报幕统一**（2026-07-25）：正式入口加载成功后，沉浸外壳先播放约 6.5 秒总片头：暗绢字粒游移，“量子游园”四字逐个由乱码坍缩成真字，再显“观之·即现”；可点击“略过”或按 Escape、Enter、Space 跳过。片头只在正式入口播放，逐幕调试、设备配置与八幕内部换页不得重复。片头结束后，以不超过 30 秒可读完的预备幕说明“观测使园林显现”，再让观众选择“指针观游”或“目光观照”。方式选择本身就是取得声音与全屏权限的首个真实手势；选指针后直接报第一幕，选目光后先请求摄像头并完成九字校准，再报第一幕。选择目光不得提前启动第一幕：预备幕保持全遮挡，校准景先成立并至少画完一帧再撤幕。权限等待态必须保留“改用指针”，取消后的迟到异步结果不得自行开启摄像头。八幕一律按“量子游园小眉题 → 第 X 幕 → 幕名 → 一句剧情 → 一句交互提示”五层排列；夜绢遮罩、字号、间距、按钮和淡出节奏统一。正式旅程各幕自动报幕约 2.2s，不重复索要点击；若入幕同时请求系统权限，倒计时从权限请求完成后开始。跨页离场只留纯黑帘，不得回显旧幕报幕。测试总览直入各幕时停在同一报幕页，按钮统一为“进入此幕”。`?act=0` 必须报“一園春”，不得退回总标题。
- **左下不是通关播报器，而是随行题跋**（2026-07-24）：探索时，游标/有效目光在同一语义物象附近稳定约 0.42s，解说它与《牡丹亭》剧情和意象的关系；机关真实改变时，事件回执锁定约 7–8s；只有出口、权限或卡住时才说动作。三层优先级为行动提示 > 事件回执 > 探索解说。低优先级“已亮几成”不得吃掉刚发现的内容，进度最多每一至二成报一次。左下结构统一为“语境标签／题目／解释／可选动作”，不做卡片，不逐字粒闪烁。桌面正文 16px、题目 19px、标签与行动行 12px，宽度上限 680px；窄屏正文 15px、题目 18px。原文、白话解释、装置自拟句与量子借喻必须明确区分。第一幕尤其不得借物象预告后幕：只说麗娘与春香此刻在园中所见所感，不点破《寻梦》、写真、离魂、回生或尚未登场的人物。所有热点的命中物象、左下四层全文、声 cue、优先级与恢复条件以 `量子游园·交互规格手册.md` 的“舞台总谱”为文字真源，代码与总谱必须同次更新。

### 2.7 设备协调原则（族规，2026-06-12 一葳定）
- **观众不看设备清单，但必须主动选择观游方式。** 预备幕只问“用指针还是用目光”，不暴露摄像头型号、麦克风型号或技术参数；这不是设备问卷。协调分两层：
  ① **方式选择 + 能力探测 + 优雅降级**（面向观众）：无麦克风→提示点按/空格惊梦；无摄像头或拒绝权限→回到指针游园。选择结果存于当前 session，并随八幕延续。
  ② **布展配置页 `?setup=1`**（面向布展者）：列出全部摄像头/麦克风设备，预览画面+吹气电平条实测，选定存 localStorage（`qg_cam`/`qg_mic`），观众入园即生效。它同时是开展前的"乐器检查"仪式。
- **摄像头锁内建**（脸必须对着屏幕；iPhone/iPad/Desk View 拉黑，布展页可改）；**麦克风保持自由**——iPhone 连续互通麦=可捧在手里的"气息法器"，是 feature 不是 bug。
- 目光交互只承担**大范围扫视型**任务（定墙/扫景/方向引导），精度上限 ±2–4cm；点击类精细操作永远保留鼠标/触屏。

### 2.8 视觉语言（2026-07-13 立）
- 完整公理、token、状态映射和交付红线见 `量子游园·视觉语言.md`；视觉改动先改该文档，再改实现。
- 核心隐喻：界面是“一卷等待观测的夜绢园林”。未观测=冷墨，凝真=骨白，过程=旧金，可行动=朱砂。
- 界面不得成为中央卡片或底部工作台：幕名寄左上，题跋寄左下，工具寄右上，园林字景始终占据最大视觉体量。题跋不移到中间；主画布左下约 `x=0–5.8、y=6.55–9` 是字幕安全区，幕名大字、门、人物面部、锚字和必须点击的目标必须避开。
- 夜绢材质禁止 3px/6px 频率的满屏横竖网格（大屏与截图会产生摩尔纹）；只保留低频绢纹、微粒与有物理理由的光晕。

## 3. 目光觀照（WebGazer）

- 入口：预备幕“目光观照”，以及各幕右上「目」。按需注入 `webgazer.js`。
- **开关全程可见**：驚夢臺不使用目光增益，但仍保留右上「目」。点击关闭必须结束 WebGazer 并停止 MediaStream 轨道，让摄像头指示灯熄灭；再次开启重启采集并复用有效九锚。校准场也必须保留「目」作为退出路径。肆至捌由 `gaze-runtime.js` 接续当前 session 的方式选择与九锚修正；从独立幕回到主文件时，同一旅程若已有有效九锚则自动接续，不得重复拦截校准。
- **退出分三级**：权限等待可“改用指针”；校准中右上可见文字必须是“退出校准”，点击即停摄像头并继续指针旅程；幕内右上“×”打开确认层，正式旅程结束后清理输入、退出全屏并回预备幕，调试直入则回测试总览。退出全屏不等于结束作品，重入园林必须经过黑场与第一幕报幕。
- **必须 localhost**（file:// 直接提示用启动器）。
- 启动顺序（有坑，勿改）：`webgazer.params.*` 预设关闭预览/人脸框/红点 → `setGazeListener` → `await begin()` → **begin 之后**才调 show* 方法（每个单独 try）。begin 之前调会摸不存在的 video 元素抛 TypeError。
- **校准=「九字小景」·看字敲击版**（2026-06-13，一葳定）：独立成景不叠任何一幕——九枚叠加态字粒散于外八方+中宫（柳月亭/松桐/山池燭，**中宫最后一枚=瞳，校准的收官一击即"點睛"**）。交互：**眼睛只管看那枚字，左键或空格随处敲三下即可确认**——不必去找鼠标、不必点中字（找鼠标=目光离字=样本变脏）。实现：校准期 `webgazer.removeMouseEventListeners()` 掐掉库的"点哪看哪"默认训练，每击显式 `recordScreenPosition(字位)` 以**所看之字**为真位喂样本；为触发 WebGazer 自带 IndexedDB 落盘，只在该击内临时挂回内建 listener，并在 `body` 合成一次同锚点 click，随即再次移除——真实手位从不进入模型。校准毕保持 `removeMouseEventListeners()`，模型冻结。**校准期目光金圈与手形光圈一并隐藏**——画了就会引目光离字。
- **校准后模型冻结·绝不再用点击在线训练**（2026-06-13 根因修复）：本作目光司扫视、点击归手，**点击位置≠注视点**；若保留 webgazer 的 `addMouseEventListeners` 默认训练，游玩中每次点门/点按钮都会被当成"你在看这里"喂进模型，**越点越歪，后幕（尤其扫墙）视点乱飞**。故校准结束即 `removeMouseEventListeners()` 全程保持——模型停在校准那一刻，配合九锚 warp 全程稳定。（曾在 finishCalib 误加 addMouseEventListeners，是后幕漂移之根因，已删。）
- **目光视点 = 一只古画丹凤眼**（2026-06-13，一葳定，**禁现代/日式眼 icon**）：canvas 细笔勾描——内眦低、外眦上挑，上睑重下睑轻，小瞳偏内，金线如朱砂，与"字粒金"同语；随凝视度 `GAZE.gain` 微微睁阖（看得越定，眼越睁越亮）。`drawGazeEye()`。不再用与鼠标雷同的小圆圈。
- **先跟随后精校**：begin 成功立即接管指针（粗校），九点校准在跟随中进行——观众先看到"它在动"，校准是"把它调准"。
- **九锚修正场**（2026-06-12）：27 击校准同步采样"原始预测 vs 锚点真位"（每点三击取均），生成九锚偏差场；锚点、预测与偏差均存归一化坐标，resize/全屏后仍有效；运行时按反距离加权（IDW）逐帧修正。结果存 localStorage（`qg_gaze_warp`），**刷新不丢**；webgazer 回归模型亦 `saveDataAcrossSessions=true` 留存。少于七个有效预测不得谎报完成，降级为粗略跟随，并允许停「目」再开重校。
- **设备选定**：摄像头优先 localStorage `qg_cam`（布展页），否则 内建白名单/iPhone 黑名单 自动挑；麦克风用 `qg_mic`。
- **校准的正确姿势（必须向观众讲清）**：**眼睛看字，手随处敲**——左键空格皆可，敲三下换下一字。人眼瞄准永远精准，校准修的是模型估计与真实视线的差；手在哪无关紧要，所以不让手出镜。
- **目光"凝视才算数·扫视不点亮"**（2026-06-13 二次调，一葳实测"瞟一眼点亮整屏／视点晃／不准"后定）：三招治本——
  ① **自适应平滑**：视点平滑系数随眼动幅度变（`a=clamp(step/110, 0.05, 0.42)`）——静止时 a≈0.05 重平滑（视点稳如定点，治"一直晃"），转移时 a 升高跟得上（不滞后）。
  ② **凝视度门控** `gStill=clamp((120−spd)/105,0,1)`（`spd` 为眼动速度的指数平滑估计）：眼动慢（<15px/帧≈凝视）gStill→1 全力点亮；快（>120≈扫视）gStill→0 **完全不点亮**。人眼"看着哪点哪"，扫视掠过的不算交互——这是"瞟一眼点亮整屏"的根治。
  ③ **判定区收回** `RG=BRUSH×1.05`（≈手大小，不再 ×1.45+内圈满格）：视点已稳，无须靠放大兜误差；最后一个预测超过 650ms 即视作失联，旧坐标不得继续驻留、点亮或触发门。
  ④ **凝视驻留增益**（2026-06-13 三次调，一葳"看实了却推不到点亮/丽娘很难到自主移动"）：目光停在一片（容忍 `BRUSH×0.8` 内的微扫视，中心缓随）即累积 `GAZE.dwell`；有效观测力 `gGain=max(gStill, min(1, dwell×1.7))`——停留约 0.6s 即满力，**"持续看着"必能一路推到点亮（c>0.8 弹诗 / 组均>0.92 人物游走），不必把目光钉死在一个像素上**。微扫视不清零，目光投向别处才重新计时（扫视仍不累积）。
  一園春弹奏圈对目光 `×1.05 进 / ×1.5 出` 且需 `gGain>0.4`。手的判定一概不变。**注**：系统性偏置（如"看上显示偏下"）由九字小景校准的九锚 IDW 修正场抵消，换人/偏多必须重校准。
- **独立幕不得把目光裸映射成永久鼠标**：`gaze-runtime.js` 同样应用速度门控、约 0.6s 驻留增益与 650ms 新鲜度；扫视时撤销合成指针，预测中断或关「目」时立即派发 `pointerleave`，旧注视点不得继续描像、护焰或点亮。设备启动/停止反馈使用独立状态条，不得改写本幕任务提示；加载与 `begin()` 各有十二秒上限，加载中再次按“目”即取消并回指针。
- **目光司扫视，点击归手；唯"过门"走月轮渐盈**（2026-06-12 一葳终定）：目光是**第二只观测之手**——与鼠标各有指示（金点=目，柔光圈=手），点亮判定取两者之并；牵丝/行廊等扫视任务手目皆可；普通点击（再夢/链接等）只认鼠标。**例外=门**：目光大致落在门左近（判定半径×1.7，宽厚为度），目点旁一轮小月自朔渐盈（1.4s），**盈满即过**；目光浮动不清零、缓退（dt×0.5）。中式进度语：不用进度条用月相。

### 幕⑤ · 離魂（量子概念：退相干不可逆——观测能延缓，救不了）※档于 `新幕/伍·離魂.html`
- **戏文**：《闹殇》中秋雨夜杜丽娘病殁。终句考证更正为【尾聲】原文「**怎能勾**月落重生燈再紅」（"但願那…"系演出本改词）；题词「冷雨幽窗燈不紅」同折。
- **结构**：满屏细雨渐密｜麗娘卧影（左）｜燭+焰簇=全场唯一暖光｜月 c 封顶 0.5 且随生命西沉（雨夜无月——"月落重生"的前提）。
- **交互**：生命值 V 单调衰减；**遮挡=观众的手**（2026-07-25 恢复最初设想）：指针移近焰尖旁（<1.75×BRUSH）即化为一只线描的手。手保持僵定的拢护姿态，只跟随观众的位置，不随风摆、不化作荷叶或其他道具；护焰强度 `q` 由手与焰尖的距离连续决定。焰尖仍随风摆，观众要把手留在它身旁。
  - **松手有预警、可回护**：衰减 `dec = 0.005+0.006×rainK + exposure²×(0.065+0.055×(1−V))`。`exposure` 在离手 1.5 秒前保持 0，随后用 2 秒平滑升至 1；所以手移开后先见焰摇，再慢慢暗下，不会在三四秒内骤灭。任何尚未熄灭的时刻把手移回，`exposure` 随计时清零，立刻止住额外下降；已经失去的 V 不回升，仍符合退相干只降不升。
  - **火焰即时反应**：`calm=1−0.82×protectK`（护得越好越稳越直越亮）、`expose=1−protectK`（没护住=雨打风欺，持续乱抖+偏斜+忽明忽暗）——非写定表演。
  - 自主风每 15–25s 一阵（护焰=挡风）；**吹气=风**（V 骤减 0.06）；烛芯随 V 下沉=无 HUD 进度条；V=0 烛灭→满园字粒散落→魂粒上升→金句徐现，句中「燈」自冷玉复红泛金=出口（**清宫 1046.5，与惊梦台再夢同音——律制闭环**）→拾畫。
- **哲学**：机制化悲剧——护焰真实有效却救不回，绝望反问「怎能勾」由出口的复亮作答。

## 8. 已知坑（踩过的，别再踩）

1. **headless Chrome `--virtual-time-budget` 下 rAF 只跑几帧**——验证连续动画必须用真实浏览器（Chrome DevTools MCP / 真人）。
2. **file:// 拿不到麦克风/摄像头**——一切权限类功能必须 localhost（`启动.command`）。
3. **webgazer：begin() 之前调 show* 会 TypeError**；**校准点击不可 stopPropagation**（吃掉训练样本=模型全废）。
4. 给 AI 发全屏 Retina 截图（>5MB）会卡死会话——截局部窗口。
5. 本机 vault 的 `.git` 会被大文件膨胀——PDF/视频/素材不进 Git（webgazer.js 1.9MB 属代码，可进）。
6. MCP 测试浏览器激活标签页会产生**真实点击**——自动化验证时先把 `advance` 钉死再测。
7. 显示真字阈 0.55 / 事件阈 0.8（两者已脱钩，原因见 §2.1）；GUIDE 换目标阈值必须 0.97（见 §5 幕一）。
8. **第三方库的"静默失败"要警惕**：webgazer 内部脚本加载失败只 resolve 不报错，炸点远离根因（mediapipe 模型 404 → 几层之后才 TypeError）。排查这类问题直接抓 console.error 完整堆栈定位压缩坐标。
9. **跨页目光不得遗留合成指针**：暂停、失联或离页必须触发 `pointerleave`；否则独立幕的 `mouseOver` 会停在最后一个注视点，观众已经关目仍可能继续推进任务。
