# 《量子游园》交互规格手册

版本：v1.1

落盘日期：2026-07-24

对象：八幕主作品、沉浸外壳、测试总控、设备配置与目光校准

状态：实现对照版。凡写“已实现”的行为均有代码定位；真实目光、吹气、连续动效与展场尺度仍须真人验收。

## 0. 手册用途

本手册回答四件事：观众每一步看见什么、可以做什么、系统如何回应、失败时怎样继续。

它不是概念文案，也不是宣传稿。概念与参数真源仍是 `量子游园·交互设计文档.md`；本手册负责把概念翻译成可执行、可测试、可追责的观众流程。

行为断言优先采用文件、函数或节点名；旧条目保留的行号只用于定位附近代码，不作为长期接口。

验证状态分三类：

| 标记 | 含义 |
|---|---|
| 已实现 | 当前代码存在明确行为 |
| 已静态验证 | 脚本解析、资源、路由或 HTTP 已核 |
| 只能人来验 | 需要真实视觉、身体、摄像头、麦克风或全屏连续体验 |

## 1. 作品总命题

观众不是在菜单中选择剧情，而是在观看、呼吸、守护、呼唤和牵引中改变园林的显现路径。

工程变量 `c` 统一称“凝定度/显真度”，范围 `[0,1]`。`c` 越高，字越稳定、越接近本色。它不是严格物理意义上的量子相干度，不得对外宣称为真实量子数据。定义见 `量子游园·交互设计文档.md:27`。

全作的量子映射按严谨度分三层：

| 层级 | 幕 | 允许的表述 |
|---|---|---|
| 机制强映射 | 一園春、驚夢臺、寫真 | 观测显真、测量坍缩、不可克隆之墙 |
| 结构映射 | 尋夢廊、離魂、糾纏橋、三生路 | 边界、不可逆损失、路径分支、多世界叙事 |
| 诗性借喻 | 拾畫·叫畫 | “传态”是戏剧结构借喻，不宣称实现量子隐形传态 |

“再夢”是重新制备一次叠加态，不是把同一次测量物理逆转。实现位于 `量子游园·丙·交互体验.html:542`。

## 2. 支持范围与入口

### 2.1 正式入口

正式体验从 `沉浸.html` 进入。外壳用同源 iframe 承载八幕，开放 camera、microphone、fullscreen、autoplay；内部页面换幕时外壳不换页，因此全屏可跨幕保持。`沉浸.html:39`、`沉浸.html:42`。

默认路由进入一園春；`scene=1…8` 只供测试。三生路额外接受 `fate=yuan|shang|hua`，非法值回退 `yuan`。`沉浸.html:48`、`沉浸.html:64`。

外壳首次载入有极细进度标记；十二秒未完成时显示重试，不让黑屏同时承担“艺术留白”和“系统故障”两种含义。

正式入口加载成功后，必须先播放总入场动画，再揭开预备幕。入场动画属于沉浸外壳，不属于第一幕，也不由 iframe 内的幕页承担：

1. 暗绢中有少量未定字粒缓慢游移。
2. “量、子、游、园”依次在乱码闪变后凝成骨白真字。
3. 上方保留“《牡丹亭》×量子观测”，下方依次出现“观之·即现”和“一座尚未定形的园，正等你看见”。
4. 全程约 6.5 秒，完成后淡出约 1.05 秒，随后才显示预备幕。
5. 观众可点击“略过”、点击背景，或按 Escape、Enter、Space 跳过。减少动态偏好下直接显示定稿标题，约 1.1 秒后进入预备幕。
6. 动画只在正式入口播放一次；`scene=1…8`、旧 `act=N`、`debug=1` 与 `setup=1` 直入均跳过，避免阻碍逐幕测试。内部 iframe 换幕不重载外壳，因此八幕途中不会重复播放。

### 2.2 横屏约束

正式舞台是 16:9 横向园林。宽度不超过 720px 的竖屏设备由外壳显示“请横置屏幕”，不压缩成不可读的横条，也不裁掉左右门位。`沉浸.html:32`、`沉浸.html:41`。

目标展机：横屏 Chrome，localhost，建议 1920×1080 或同比例更高分辨率。

### 2.3 测试总控

`测试总览.html` 允许逐幕进入，不改变正式单向状态机；顶部“预备幕”可用 `沉浸.html?prelude=1` 强制复测方式选择。八幕入口位于 `测试总览.html` 的逐幕路由表。

环境状态只能报告“localhost 安全上下文和媒体 API 存在”，不得谎报真实摄像头、麦克风或权限已可用。当前文案见 `测试总览.html:143`。

最近打开的第 1 至第 7 幕会在总控中留下朱砂细标，便于重复调试。`测试总览.html:144`。

## 3. 全局页面构成

正式舞台只保留四个固定信息区：

| 区域 | 内容 | 规则 | 代码 |
|---|---|---|---|
| 左上 | 幕号、幕名、当前相位 | 低对比，不抢园林 | `量子游园·丙·交互体验.html:124` |
| 左下 | 园中解说、事件回执、行动提示 | 探索时讲物象与戏文；机关变化时短暂让位给结果；出口显形后才给通关动作 | 主作品 `#hintLabel/#hintTitle/#hint/#hintAction` |
| 右上 | 再梦、目光、重看、全屏 | 熟悉符号优先，均有 aria-label | `量子游园·丙·交互体验.html:128` |
| 右下 | 空格、前进、重看 | 桌面弱提示；窄屏隐藏 | `量子游园·丙·交互体验.html:139`、`:110` |

新幕肆至捌沿用同一空间语法：幕名左上、提示左下、操作右上、键位右下。例见 `新幕/肆·寫真.html:113`、`新幕/伍·離魂.html:122`、`新幕/陸·拾畫叫畫.html:103`、`新幕/柒·三生路.html:109`。

界面不得出现中央参数面板、进度仪表盘、解释量子概念的卡片或装饰性大按钮。朱砂只表示可行动或关键交互，骨白表示凝真，旧金表示过渡与记忆，冷玉表示未定。

左下解说不是教程栏，而是观众与《牡丹亭》文本之间的随行题跋。它固定采用四层：11px 朱砂语境标签、17px 旧金题目、14px 骨白解释、11px 冷玉行动句。行动句前用朱砂箭头，只有当前确有下一步动作时出现。桌面宽度不超过 620px；窄屏占可用宽度，不得遮住出口或右下键位。

### 3.1 预备幕

总入场动画结束后才进入预备幕。预备幕只拦截一次全新正式旅程；测试直入、设备配置与已经开始的同一 session 不重复询问。测试时可用 `?prelude=1` 强制打开。

观众在一个屏幕内完成两件事：

1. 在 30 秒内读懂“园林尚未定形；指尖、目光与气息会改写显现”。
2. 二选一：指针观游，或目光观照。

指针观游使用鼠标/触控完成观测，过门与精细动作仍由手完成。目光观照先申请摄像头权限，再进入九字小景；九字校准结束后才报第一幕。选择目光时不得提前调用 `enter()`：预备幕保持全遮挡，校准状态先成立并至少画完一帧，再撤下预备幕；第一幕画布、报幕或幕内 UI 不得在其间漏出。等待态始终提供“改用指针”；权限拒绝、设备缺失、脚本载入失败或观众主动改选时，系统明确回到指针模式并继续，迟到的异步启动结果必须被取消，不能把观众困在黑场或在入幕后自行开目。

方式选择本身是首个真实用户手势，用于申请全屏和解锁声音。选择结果写入 `sessionStorage.qg_input_mode`；右上「目」在八幕及校准场中全程可见，可随时关闭摄像头或重新开启目光。跨页进入主文件时，同一旅程且已有有效九锚应自动恢复，不重跑校准；新开目光或九锚缺失才进入校准。实现入口：`#prelude`、`chooseInputMode()`、`finishGazePrelude()` 与启动段 `_resumeGaze`。

### 3.2 入幕遮罩

八幕使用同一套报幕结构，不允许独立幕各写一套：

1. 小眉题：`量 子 游 園 · 《牡丹亭》 × 量子观测`
2. 幕号：`第 壹/貳/參/肆/伍/陸/柒/捌 幕`
3. 幕名：分字排布的大字标题
4. 一句剧情：说明人物此刻处境
5. 一句交互提示：只说本幕的第一动作

统一视觉参数：遮罩 `rgba(7,16,14,.94)`；幕名 `clamp(36px,6vw,64px)`；剧情上距 24px、最大宽 640px；交互提示上距 16px、最大宽 560px；遮罩淡出 0.7s。测试直入按钮统一为“進 入 此 幕”，使用朱砂上下细线，不使用圆角卡片。

预备幕完成后报“第一幕·一園春”，约 2.2 秒自动进入，不再要求第二次点击。方式选择手势已经完成：

1. 遮罩淡出。
2. 尝试请求外壳全屏，失败静默保留右上全屏按钮。
3. 激活 AudioContext。
4. 入幕时写入 `sessionStorage.qg_journey_active=1`。
5. 第一声磬在约 360ms 后出现。

实现见 `reportFirstAct()` 与 `enter()`。

正式旅程一旦开始，第二至第八幕以及终幕回到第一幕都按同一完整模板报幕约 2.2s 后自动进入，不要求观众重复点击。主文件内部过幕由 `showActCard()` 承担；跨文件过幕由各页 `journey` 状态承担。首次进入需要系统权限的幕，2.2 秒倒计时必须从权限请求完成后开始，不能让摄像头或麦克风弹窗吞掉报幕。跨文件离场只允许纯黑帘，禁止复用旧幕 `#enter` 造成“旧幕再报一次、新幕又报一次”。`?act=3` 进入糾纏橋时，只要 session 仍在正式旅程且 URL 不含 `debug=1`，必须自动续播。

终幕返回一園春时，同一 session 报“第一幕·一園春”后自动重入，不重新拦截入园。

测试总览为每个链接追加 `debug=1`。调试入口始终显示完整五层报幕和“進 入 此 幕”按钮，方便逐幕检查；不得因为浏览器里残留 `qg_journey_active` 而自动跳过。

## 4. 全局交互语法

### 4.1 指针与触控

系统光标在画布中隐藏，作品绘制柔光圈、朱砂断环和中心点。靠近可行动单字时，环变亮、变大并出现中心点。

触控落指立即更新观测坐标；抬指或取消后清除，避免“幽灵手指”继续护焰、描像或点亮。主作品见 `量子游园·丙·交互体验.html:1086`，新幕见 `新幕/肆·寫真.html:611`、`新幕/伍·離魂.html:684`、`新幕/陸·拾畫叫畫.html:690`、`新幕/柒·三生路.html:579`。

### 4.2 凝定度 latch

观测影响为柔光圈内的 smoothstep。每帧上升量按 `dt` 归一：`1−0.88^(dt×60)`；60Hz 与 120Hz 不应改变主要手感。主作品实现 `量子游园·丙·交互体验.html:808`，肆幕 `新幕/肆·寫真.html:417`，伍幕 `新幕/伍·離魂.html:462`，陆幕 `新幕/陸·拾畫叫畫.html:418`，捌幕 `新幕/柒·三生路.html:451`。

全局阈值：

| 阈值 | 含义 |
|---|---|
| `c >= 0.55` | 主作品显示真字 |
| `c >= 0.8` | 事件、锚字或新幕真字判定 |
| 组均 `> 0.85` | 糾纏橋人物判“明” |
| 组均 `> 0.92` | 一園春人物魂醒、开始游园引导 |
| `c >= 0.97` | 一園春引导换下一个锚字、圆世候字完成 |

阈值实现见 `量子游园·丙·交互体验.html:823`、`:811`、`:920`、`:970`，参数真源见 `量子游园·交互设计文档.md:220`。

### 4.3 单字门

出口不是按钮卡片，而是场景内单字。门有暗底衬纸、朱砂/旧金呼吸与足够大的隐形触区；出现时间约 2.6s。主作品绘制 `量子游园·丙·交互体验.html:856`，新幕例见 `新幕/肆·寫真.html:491`、`新幕/柒·三生路.html:514`。

点击门或在门已开放时按右箭头出幕。空白处无效。

### 4.4 键盘

| 键 | 正式行为 |
|---|---|
| Enter | 入园/入幕 |
| Space | 入园；驚夢/再夢；叫画一声；離魂轻风 |
| ArrowRight | 仅门已开放时前行 |
| R | 重置当前幕 |
| F | 进入/退出全屏 |

持续按键产生的 `repeat` 被忽略，防止长按 Space 连续惊梦、吹风或叫画。主作品见 `量子游园·丙·交互体验.html:1109`，伍幕 `新幕/伍·離魂.html:699`，陆幕 `新幕/陸·拾畫叫畫.html:711`，捌幕 `新幕/柒·三生路.html:593`。

### 4.5 减弱动效

系统 `prefers-reduced-motion` 开启时，字形闪烁、漂移、呼吸和 CSS 动画被冻结或显著削弱，但任务、门和文本仍可完成。主作品 CSS `量子游园·丙·交互体验.html:114`；肆至捌见各文件的 `REDUCED_MOTION` 与对应 media query。

### 4.6 暂停、退出与返回

退出必须分清三个层级：

1. 摄像头授权等待：预备幕保留“改用指针”，取消后继续第一幕。
2. 九字校准：右上按钮的可见文字改为“退出校准”；点击后停止摄像头、回到指针并继续第一幕。
3. 任一幕内：右上“×”打开作品内确认层。正式旅程确认后停止摄像头与麦克风、退出全屏、清空本次 session，并回到预备幕；`debug=1` 确认后返回测试总览。取消必须回到原幕且不丢进度。

“退出全屏”只改变显示状态，不等于结束游园。右上“重入园林”属于重新开始，必须先走黑场和第一幕报幕，不能瞬切并无提示地丢掉当前进度。全局退出实现由 `journey-controls.js` 统一注入主作品与四个独立页面。

### 4.7 性能边界

Canvas DPR 上限为 2，同时限制单画布约 800 万物理像素，防高分屏双 Canvas 占用失控。主作品 `量子游园·丙·交互体验.html:1072`；肆幕 `新幕/肆·寫真.html:596`；伍幕 `新幕/伍·離魂.html:675`；陆幕 `新幕/陸·拾畫叫畫.html:676`；捌幕 `新幕/柒·三生路.html:569`。

### 4.8 随行解说优先级

左下信息必须分三层，禁止再退回“从入幕到出幕始终只报通关进度”：

1. 探索解说：鼠标或有效目光在有语义的物象附近稳定停留约 0.42s 后出现。按语义分组，不按单个随机字粒逐帧更新；离开后保留最后一条供阅读，再次移回同一物象必须能够重现。第一幕“徑”显现后仍以物象解说为主：快速扫过不换稿，物象之间移动不插播出口，完全离开语义物象 3.2s 后才恢复完整的“循徑出园”提示；当前物象题跋底部只保留低频轻闪的出口行动句。
2. 事件回执：人物魂醒、锚字看真、点睛失败、画卷展出、灯灭、记忆锚完成等真实状态改变发生时出现，锁定约 7–8s。低优先级进度文案不得覆盖它。
3. 行动提示：权限失败、卡住兜底、门已显等需要观众立即操作时出现。普通进度最多每一至二成更新一次，不得按每个百分点评播。

幕二坍缩后的逐句解说属于固定题跋：在再梦或过门前持续可读；摄像头等临时系统提示结束后应恢复。解说必须区分原文、剧情释义、装置自拟句与量子借喻，不能把装置阐释伪装成汤显祖原文。

背景材质使用低频绢纹与有限颗粒，禁止 3px/6px 满屏横竖网格。

### 4.9 字幕台口与舞台总谱

左下题跋是全作固定的“字幕台口”，不移到屏幕中间。中部是八幕共同的核心表演区：人物相遇、吹气坍缩后的诗句、寻梦廊深处、写真画像、离魂烛焰、叫画立轴、纠缠桥与三生路主物都经过这里。把字幕移到中间会让每一幕重新躲避 UI，并直接遮挡观众正在观测的目标。

桌面题跋宽度上限 680px，正文 16px／1.72 行高，题目 19px，语境标签与行动行 12px；窄屏正文 15px、题目 18px。主文件虚拟画布左下约 `x=0–5.8、y=6.55–9` 为字幕安全区：幕名、门、人物面部、锚字和必须点击的目标不得放入。装饰字允许从暗底后方经过，但不能形成可读的大字与正文争夺视线。第三幕“尋夢廊”景名固定在右下 `x≈12.35、y≈8.28`。

每一个可交互热点必须在本手册留下六项记录，缺一项即视为规格不完整：

1. 幕与阶段。
2. 可命中的语义物象或按钮，不以随机字粒编号代替。
3. 观众动作及驻留时间。
4. 画面状态改变。
5. 左下四层原文：语境标签、题目、正文、行动行。
6. 声音、锁定时长、退出或恢复条件。

代码新增、删除或改写热点时，必须同次提交更新对应幕的“题跋与声场总谱”。不得只把词藏在 JavaScript 字典里，也不得让手册写着已经下线的台词。

## 5. 设备配置流程

入口：`沉浸.html?scene=1&setup=1`，或测试总控“设备检查”。

配置页只给布展者，不给观众。页面载入时不自动索取权限；必须由布展者分别点“开启摄像头预览”和“开启麦克风监听”。实现 `量子游园·丙·交互体验.html:1316`。

### 5.1 摄像头

1. 页面先列出当前可枚举的视频输入；未授权前标签可显示“摄像头 1”。
2. 布展者选择设备。
3. 点击预览后才调用 `getUserMedia`。
4. 成功后显示 150px 高本地预览，重新枚举以补全设备名。
5. 切换下拉项时，已有预览才会重启流。
6. 保存后写入 `localStorage.qg_cam`。

实现见 `量子游园·丙·交互体验.html:1342` 至 `:1366`。

默认选择策略：已保存设备优先；否则内建/FaceTime/Integrated 优先，iPhone、iPad、Continuity、Desk View 回避。`量子游园·丙·交互体验.html:1170`。

### 5.2 麦克风

1. 布展者选择输入设备。
2. 点击监听后才请求权限。
3. 电平条显示实时 RMS，只用于确认输入有效，不宣称已通过吹气阈值。
4. 保存后写入 `localStorage.qg_mic`。
5. 已保存设备失效时，正式各幕回退系统默认麦克风，而不是直接失声。

主作品麦克风回退见 `量子游园·丙·交互体验.html:602`；伍幕见 `新幕/伍·離魂.html:346`；陆幕见 `新幕/陸·拾畫叫畫.html:355`。

摄像头和麦克风各自使用独立异步序号；同时开启不会互相误判为过期请求。`量子游园·丙·交互体验.html:1337`。

关闭配置页、进入校准或离开页面时，预览流、监听流、Analyser、rAF 与 AudioContext 全部清理。`量子游园·丙·交互体验.html:1364`。

## 6. 目光交互规格

### 6.1 边界

目光入口存在于八幕右上。主作品中，一園春、尋夢廊、糾纏橋接受目光观测；驚夢臺仍以气息为唯一主通道，目光增益归零，但开关不能隐藏，观众必须能随时停止摄像头交互。

独立幕肆至捌通过 `gaze-runtime.js` 读取 `sessionStorage.qg_input_mode`，按需接续摄像头、已存 WebGazer 模型与 `qg_gaze_warp`。目光作为第二个大范围观测指针参与描像、护焰、扫石与记忆显真；精细点击、叫画确认、门与工具仍由手完成。

目光承担大范围观测、沿廊、牵丝和门驻留；精细按钮、再夢、重看仍由手操作。

### 6.2 启动

观众在预备幕选择目光，或在任一幕点击右上“目”：

1. 检查 localhost 与 `getUserMedia`。
2. 按需加载本地 `webgazer.js`。
3. 在 `begin()` 前配置隐藏预览、人脸框和红点。
4. 设置 listener。
5. `await webgazer.begin()`。
6. begin 后再次调用 show* 关闭可视组件。
7. 首次启用或九锚缺失时进入九字校准；同一旅程跨页恢复且九锚有效时直接接续。

首次正式选择的启动顺序实现见主页面 `gazeStart()`。独立幕接续见 `gaze-runtime.js:start()`；其页面位于 `新幕/` 下，所以必须显式使用 `../webgazer.js` 与 `../mediapipe/face_mesh`。begin 前不得调用会访问尚未创建 video 节点的 show* API；begin 后的 show* 必须逐个兜错，冻结点击训练不得和装饰性调用绑在同一条链上。

加载和授权期间 `GAZE.loading` 保持为 true，重复点击不会发起第二套 begin。预备幕始终保留“改用指针”；独立幕的“目”在加载中改成“取消目光启动”，脚本与 `begin()` 各有十二秒上限，取消、超时或失败统一结束媒体流并回到指针。设备状态使用独立 `#qgGazeStatus`，不得覆盖或定时隐藏本幕 `#hint` 操作说明。`量子游园·丙·交互体验.html:1151`、`gaze-runtime.js:start()`。

### 6.3 九字小景

校准是独立画面，不叠在任何戏幕上。九点顺序为外八方后中宫，最后一字是“瞳”。`量子游园·丙·交互体验.html:1121`、`:1207`。

每一点：

1. 眼睛只看当前字。
2. 左键可在任意位置敲三下；Space 等效。
3. 手不需要去找字，避免目光离开锚点。
4. 每击把“字的位置”显式送入 `recordScreenPosition`。
5. 同时采集 WebGazer 原始预测，用于九锚偏差场。

实现见 `量子游园·丙·交互体验.html:1207`、`:1212`。

摄像头权限弹窗若使外壳退出全屏，校准第一次手势只负责接回全屏，不计样本。`量子游园·丙·交互体验.html:1213`。

WebGazer 的公开 `recordScreenPosition` 不会自动把回归数据写入 IndexedDB；当前实现只在每个校准击内临时挂回内建 click listener，在 body 合成同锚点 click，随即移除，保证持久化而不把真实手位训练进模型。`量子游园·丙·交互体验.html:1221`。

### 6.4 校准成功与失败

九点原始预测至少七点有效才算精校完成。少于七点：

1. 不显示“校准成功”。
2. 删除旧 warp。
3. 保留粗略跟随。
4. 提示调整光线和坐姿。
5. 停“目”再开时重新进入校准。

实现 `量子游园·丙·交互体验.html:1241`。

成功后保存归一化九锚偏差场 `qg_gaze_warp`；归一化坐标保证 resize 和全屏切换后仍按相对屏区修正。`量子游园·丙·交互体验.html:1246`。

### 6.5 运行时观测

WebGazer 原始预测先经过九锚 IDW 修正，再经过自适应平滑。眼动小则强平滑，转移大则快速跟随。`量子游园·丙·交互体验.html:1178`。

有效目光必须满足：

| 条件 | 值 |
|---|---|
| 样本新鲜度 | 最后预测小于 650ms |
| 凝视速度 | `gStill=clamp((120-spd)/105,0,1)` |
| 驻留容差 | `BRUSH×0.8` |
| 驻留满增益 | 约 0.6s |
| 观测半径 | `BRUSH×1.05` |

新鲜度门控与凝视计算见 `量子游园·丙·交互体验.html:776`。人脸离开后，旧坐标不得继续点亮、牵丝、走廊或触发门。

主作品目光指示是古画丹凤眼，不是现代圆点。只有新鲜预测且不在驚夢臺时绘制。独立幕用小型“目”标记，同时仍以 650ms 新鲜度撤销交互。

目光驻留门约 1.4s，以一轮小月渐盈；盈满后向画布派发门心 pointerdown。普通按钮不接受目光自动点击。`量子游园·丙·交互体验.html:1296`。

独立幕不得把每一个 WebGazer 样本直接当成永久鼠标。运行时必须计算速度门控与驻留增益：扫视时派发 `pointerleave`，看定约 0.6 秒后才合成 `pointermove`；最后预测超过 650ms、暂停或离页时立即撤销。实现见 `gaze-runtime.js` 的 listener、`releaseObservation()` 与 stale timer。

### 6.6 暂停与资源

再点“目”必须先从 `#webgazerVideoFeed.srcObject` 取得并停止全部 MediaStream 轨道，再调用 `webgazer.end()` 删除视频节点并撤销目光观测；顺序不可颠倒，否则节点先被删除后将拿不到真实轨道，摄像头指示灯可能不熄灭。再次开启会重新 `begin()`，但有效九锚与持久化模型继续复用，不要求重复校准。校准中点击“退出校准”同样退出校准并进入指针模式，底部说明必须明写这个结果，不能只依赖桌面 hover title。

跨页时旧页面停止摄像头轨道并清理陈旧指针；新页面只在 session 仍选择目光时重新接续。若从未完成九字校准却在独立幕首次开目，只能提示“粗略跟随”，不得显示精校成功。

## 7. 八幕逐步规格

### 7.1 第壹幕 一園春

初见：晨光落在深青绢园中。麗娘位于画面中央偏右，春香在她右侧稍下；七枚锚字“日柳山松桐亭池”都处在未定状态。第一幕发生在“晓来”“早茶时了”之后，使用春日而不是月亮；后幕的月不受影响。

第一步必须先见春香：观众用鼠标、触控或目光在画面中央偏右唤醒春香。此时麗娘与园景都不接受观测增益，左下只写“往画面中央偏右，先唤春香／有人引路，才好游园”，不得拆解人物姓名的字形、衣饰或精确坐标，也不重复说明目光与鼠标的停留方法。

春香组达到 0.78、姓名已经清晰可辨时即魂醒，不再沿用其他人物 0.92 的组均值要求，也不要求观众扫遍头饰与衣袖。她直接说《惊梦》原句“小姐，早茶时了，请行。”约 2.8 秒后，程序自动将麗娘显真并魂醒，不要求观众再找一次人物。麗娘不显示“已被唤醒”等系统回执，只以原句“不到园林，怎知春色如许。”回应。此后春香领路、麗娘观看；观众可以完全停手，把本幕当作一段游园小戏观看，也可继续用目光或鼠标帮助字更快看真。

自动游园固定走“日→柳→山→松→桐→亭→池”，不再按最近未亮锚字随机选路。每站分为四步：二人行走、周边构件按远近与次序分层起显、左下出现一段随行题跋、锚字由二人辅助看真至 `c>=0.97`。周边字粒错开 0–1.15 秒启动，以指数缓动在约 2–4 秒内升至目标相干度，不得整片瞬间定形；系统要求减少动态效果时例外。同一站不得再追加“某字已看真／稍后前往下一处”等第二层操作播报；题跋应在人物驻足期间持续可读。游客提前点亮的锚字仍按顺序到访，不得跳过；游客未点亮的景物由二人到站时代为显出。自动游园期间，到站解说优先于随机游标解说，避免静止鼠标抢走叙事。

探索解说：自动游园结束后，游标或目光停在麗娘、春香、春日、柳及枝叶丝条、亭与柱栏檐阶、牡丹、芍药、杜鹃、荼蘼、群芳、池鱼、湖山石、园墙、云雨、妆束、松桐等区域时，左下只从此刻“游园”的见闻出发，解释麗娘与春香眼中的花木、亭台、池石和春光。不得点破《寻梦》、写真、离魂、回生、柳梦梅姓名等后文，不得用“伏笔”“证物”“坐标”等论文式术语替人物感受。牡丹显示“牡丹虽好，他春归怎占的先”，杜鹃显示“遍青山啼红了杜鹃”，荼蘼显示“荼蘼外烟丝醉软”；海棠、蔷薇、兰、菊在本段曲词中未逐一点名，只使用“原来姹紫嫣红开遍”的群芳总写。芍药栏属于同出稍后的梦境，不在本幕提前引用梦境情节。锚字第一次看真时，解说与专属磬音一起出现；移开后再返回同一物象，必须重新显示同一解说。

## 10. 失败与降级

## 11. 艺术红线

1. 驚夢臺吹气前必须是满屏乱字，不得出现中间台子。

10. 任何后置特殊字必须预留白，禁止字上叠字。

6. 清空 session 后从正式入口完整走一遍八幕，核对中途不再重复“轻触入幕”。
7. 全屏开始，跨幕切换，确认外壳不退全屏。
8. 在 1920×1080 和实际展屏分辨率各走一次。
9. 横屏手机只检查布局与触控；竖屏应出现横置提示。
10. 开 DevTools 保留完整 console 堆栈；任何 error 都不得以“画面看起来正常”放过。
