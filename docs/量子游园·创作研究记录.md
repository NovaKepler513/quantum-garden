# 量子游园 · 创作研究记录

> 这里记录作品为什么改变，不只记录代码改了什么。每一条决定都应留下触发问题、文本证据、艺术判断、实现结果与未决问题，使作品的成长过程像剧本、场记与总谱一样可以追溯。

## 记录方法

每次重要迭代至少留下六项：

1. 现场反馈：观众在哪里出戏、困惑或失去兴趣。
2. 硬伤判断：问题属于文案、交互、叙事结构还是作品命题。
3. 原作证据：引用哪一出、哪一段行动或对白。
4. 艺术决定：作品要放大什么，不做什么。
5. 实现决定：画面、状态机、声部和文档怎样同步。
6. 未决问题：本轮有意不解决什么，留给哪一轮讨论。

## 2026-07-26 · 花园不是地图，而是一道被偶然打开的禁门

### 现场反馈

第一幕的左下文字虽然信息完整，却越来越像戏曲导赏、汉字释义和阅读理解答案。“杜鹃表达伤春”“群芳并未逐一点名”“装置让花显形”都站在戏外替观众下结论。观众不是在园中发现线索，而是在听讲解员解释作品。

另一个更根本的问题是：麗娘与春香一醒来就天然置身花园，游园退化成清点景物的地图任务。原作中最有力量的矛盾被跳过了：花园离麗娘只隔一墙，她却长到十六岁才第一次知道并进入它。

### 原作证据

- 《闺塾》中，春香借“出恭”离开书房，偶然发现“原来有座大花园。花明柳绿，好耍子哩”；麗娘随后追问花园所在与景致，并说“原来有这等一个所在”。这是发现花园的偶然起点，而不是二人原本就在园中。见[《牡丹亭·闺塾》](https://zh.wikisource.org/wiki/牡丹亭/閨塾)。
- 《肃苑》中，麗娘担心父亲得知，春香回答“老爷下乡，有几日了”；麗娘又看历择日、预令花郎扫清花径。游园不是随意散步，而是多个条件短暂重合后才出现的通路。见[《牡丹亭·肃苑》](https://zh.wikisource.org/wiki/牡丹亭/肅苑)。
- 《惊梦》把这一越界凝成“不到园林，怎知春色如许”。园林不只是风景，也是麗娘第一次亲身抵达书本与闺训之外的世界。见[《牡丹亭·惊梦》](https://zh.wikisource.org/wiki/牡丹亭/驚夢)。
- 《慈戒》中杜母对女子行动范围的训诫，说明“墙”并非单纯建筑，而是礼法与家内秩序的边界。见[《牡丹亭·慈戒》](https://zh.wikisource.org/wiki/牡丹亭/慈戒)。

### 两点硬伤

1. 声部越位：作品替人物分析“象征了什么”，把沉浸现场变成课堂。
2. 门槛消失：人物天然在园中，使“为什么今日才到达”这一核心悬案没有发生。

### 艺术决定

第一幕的左下文字改称“场内声部”。它只允许出现四类材料：人物当场说的话、当场动作、迟疑或未说完的念头、可由观众自行拼合的现场线索。它不承担考据展示、术语解释和中心思想总结。

作品需要一点侦探气质，但侦查对象不是谁犯了案，而是一个被日常遮蔽的事实：这样近的一座园，她为什么十六年没有来过？每个景物声部都应让这个问题多显出一层，而不是直接给出标准答案。

“量子”在第一幕也不能只等于字粒从乱码变真。它对应一条低概率路径的成立：春香误闯、父亲离家、花径被清、观众完成唤醒，数个条件同时成立，园门才由“不可去”坍缩为“可去”。观测不是替代剧情的特效，而是加入这次偶然事件的最后一个条件。

### 实现决定

1. 开场保留“先唤春香”，但春香醒后先讲误闯后园，而非直接请小姐游园。
2. 麗娘随后自动显真，只追问花园所在与景致；不显示“人物已唤醒”的系统回执。
3. 春香说出“老爷下乡，有几日了”后，二人才越过园门。
4. 人物与园景之间增加一列“墙／砖”内墙；墙左园景先被压暗，越门时墙从人物高度向上下裂开并淡去，之后自动游园才起步。
5. 第一幕二十组自由探索文字全部改写为场内声部。删除“表现、象征、反衬、原文没有逐一点名、装置让”等讲解句式，改用二人的对白、动作和现场细节。
6. 实现文本与《交互规格手册》的题跋总谱同次更新，避免台上台下两套剧本。

### 本轮有意不做

本轮不借第一幕修改之机重排八幕，也不把“量子偶然性”生硬贴到其他幕。全作结构需要单独讨论，否则局部修辞会先于总体命题作出决定。

### 下一轮结构讨论的问题

1. 每一幕究竟在追查哪一个没有被说透的问题？
2. 每一幕有哪些“原本不会发生、却因条件偶合而发生”的分岔？
3. 观众的动作是在推进通关，还是在改变人物所处的现实？
4. 八幕之间应当怎样递进：从看见、入梦、寻找，到画像、离魂、叫画、相认与三生？
5. 哪些知识应藏在作品后台，哪些只能通过人物行动在前台被发现？
